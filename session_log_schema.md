# Drowsiness Session Event Log: Schema Specification

This document specifies the format, schema structure, field definitions, and event types for the structured session event logs generated by the `SessionLogger` during system runtime.

---

## 📄 Log Format
The session log is recorded in **JSON Lines (JSONL)** format (suffix `.json`).
- Each log entry is written as a single line.
- Each line is a self-contained, serialized, valid JSON object.
- Lines are separated by a standard newline `\n` character.
- Real-time writers append events in chronological order.

---

## 🗂️ Field Definitions

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `timestamp` | `string` | ISO 8601 UTC date-time string (e.g., `YYYY-MM-DDTHH:MM:SS.mmmmmmZ` or `YYYY-MM-DDTHH:MM:SSZ`). |
| `event_type` | `string` | The identifier for the type of event being logged (see [Event Types](#-event-types)). |
| `state` | `string` | The active drowsiness state identifier (e.g., `ALERT`, `SLIGHTLY_DROWSY`, `DROWSY`, `HIGHLY_DROWSY`). |
| `score` | `float` | The aggregate drowsiness score (normalized 0.0 to 100.0) at the event timestamp. |
| `confidence` | `float` | The decision engine rule evaluation confidence percentage (0.0 to 100.0). |
| `duration` | `float` | Duration value in seconds, calculated depending on the event type (see [Durations](#-duration-calculation-rules)). |
| `message` | `string` | *(Optional)* A short text descriptor containing escalation or de-escalation remarks. |

---

## ⏱️ Duration Calculation Rules

1. **State Transition Events (`student_became_<state>`)**:
   - The `duration` represents the **exact elapsed time (in seconds)** that the *previous* state lasted.
   - Example: If a student was in `ALERT` for 10 seconds and then transitioned to `SLIGHTLY_DROWSY`, the `student_became_slightly_drowsy` event will list `duration: 10.0`.
2. **Alert Trigger Events (`alert_triggered`)**:
   - The `duration` is always set to `0.0`. It marks the point in time when an alert period commenced or was modified.
3. **Alert End Events (`alert_ended`)**:
   - The `duration` represents the **total elapsed time (in seconds)** of the active warning alert window (from the first transition out of `ALERT` until returning to a clean `ALERT` state).
   - Example: If the student transitions: `ALERT` $\rightarrow$ `SLIGHTLY_DROWSY` (at t=10s) $\rightarrow$ `DROWSY` (at t=15s) $\rightarrow$ `ALERT` (at t=22s), the `alert_ended` event is written at t=22s with `duration: 12.0` (which is `22s - 10s`).

## 📣 Event Types

### 1. `student_became_alert`
Fires when the student transitions into the `ALERT` state.
- **Example log line**:
  ```json
  {"timestamp": "2026-07-24T10:45:00.123456Z", "event_type": "student_became_alert", "state": "ALERT", "score": 15.0, "confidence": 100.0, "duration": 8.42}
  ```

### 2. `student_became_slightly_drowsy`
Fires when the student transitions into the `SLIGHTLY_DROWSY` state.
- **Example log line**:
  ```json
  {"timestamp": "2026-07-24T10:45:05.678910Z", "event_type": "student_became_slightly_drowsy", "state": "SLIGHTLY_DROWSY", "score": 35.0, "confidence": 75.0, "duration": 5.55}
  ```

### 3. `student_became_drowsy`
Fires when the student transitions into the `DROWSY` state.
- **Example log line**:
  ```json
  {"timestamp": "2026-07-24T10:45:10.000123Z", "event_type": "student_became_drowsy", "state": "DROWSY", "score": 65.0, "confidence": 85.0, "duration": 4.32}
  ```

### 4. `student_became_highly_drowsy`
Fires when the student transitions into the `HIGHLY_DROWSY` state.
- **Example log line**:
  ```json
  {"timestamp": "2026-07-24T10:45:15.543210Z", "event_type": "student_became_highly_drowsy", "state": "HIGHLY_DROWSY", "score": 85.0, "confidence": 95.0, "duration": 5.54}
  ```

### 5. `alert_triggered`
Fires when a warning sequence begins (leaving `ALERT`) or when the state escalates/de-escalates between warning states.
- **Example log line (New Trigger)**:
  ```json
  {"timestamp": "2026-07-24T10:45:05.679123Z", "event_type": "alert_triggered", "state": "SLIGHTLY_DROWSY", "score": 35.0, "confidence": 75.0, "duration": 0.0}
  ```
- **Example log line (Escalation)**:
  ```json
  {"timestamp": "2026-07-24T10:45:10.000456Z", "event_type": "alert_triggered", "state": "DROWSY", "score": 65.0, "confidence": 85.0, "duration": 0.0, "message": "Alert state modified/escalated"}
  ```

### 6. `alert_ended`
Fires when the warning sequence finishes and the system returns to a normal `ALERT` baseline.
- **Example log line**:
  ```json
  {"timestamp": "2026-07-24T10:45:20.123456Z", "event_type": "alert_ended", "state": "ALERT", "score": 15.0, "confidence": 100.0, "duration": 14.44}
  ```
