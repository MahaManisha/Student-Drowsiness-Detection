# Session Summary Report: Format Specification

This document specifies the format, headings, structure, and calculation rules for the Markdown summary reports generated by the `ReportGenerator` on application shutdown.

---

## 🏗️ Markdown Document Structure

The generated report MUST follow this exact outline and heading structure:

### 1. Document Header
- Title: `# 📋 Student Drowsiness Monitoring: Session Summary Report`
- Subtitle: `*Generated on: YYYY-MM-DD HH:MM:SS UTC*`
- A horizontal divider: `---`

### 2. Session Overview Section
- Heading: `## ⏱️ Session Overview`
- Contains a key-value Markdown table with parameters:
  - **Session Duration**: Formatted duration string (e.g. `12m 34s`) followed by raw seconds.
  - **Attentiveness Rating**: Colored emoji-based rating badge.
  - **Total Warnings Triggered**: Overall count of alert sequence triggers.
- Subheading: `### 📝 Attentiveness Assessment`
- A blockquote (`>`) detailing the qualitative assessment description.

### 3. Key Performance Indicators (KPIs) Section
- Heading: `## 📊 Key Performance Indicators (KPIs)`
- Table listing core numerical metrics:
  - **Total Blinks**: Total counts.
  - **Total Yawns**: Total counts.
  - **Average EAR**: Running session average.
  - **Average MAR**: Running session average.
  - **Highest Drowsiness Score**: Peak score (out of 100).
  - **Longest Eye Closure**: Peak eye closure duration (seconds).

### 4. State Duration Breakdown Section
- Heading: `## ⌛ State Duration Breakdown`
- Table summarizing duration, percentage, and an ASCII bar graph trend for each drowsiness state:
  - states: `Alert`, `Slightly Drowsy`, `Drowsy`, `Highly Drowsy`.
  - The bar graph represents percentage width using `█` for filled segments and `░` for empty segments (20 characters total).

### 5. Timeline of Drowsiness Events Section
- Heading: `## 🕒 Timeline of Drowsiness Events`
- Table of events parsed from the structured JSON Lines log file:
  - Columns: `Timestamp`, `Event Type`, `Drowsiness State`, `Score`, `Confidence`, `Duration`, `Description / Details`.
  - Timestamps formatted as `HH:MM:SS`.
  - Key events (e.g., `alert_triggered`, `alert_ended`) highlighted using bolding or state emojis.

---

## 🎛️ Attentiveness Rating Logic

The "Attentiveness Rating" is calculated based on state duration ratios and alert triggers:

| Rating Level | Badge | Trigger Rules |
| :--- | :--- | :--- |
| **CRITICAL RISK** | 🔴 **CRITICAL RISK** | Highly Drowsy ratio $\ge 10\%$, or Total Warnings $\ge 5$, or Highly Drowsy duration $> 30.0$ seconds. |
| **MODERATE DROWSINESS** | 🟠 **MODERATE DROWSINESS** | Drowsy/Highly Drowsy combined ratio $\ge 15\%$, or Total Warnings $\ge 3$. |
| **MILD FATIGUE** | 🟡 **MILD FATIGUE** | Slightly Drowsy ratio $\ge 25\%$. |
| **HIGHLY ATTENTIVE** | 🟢 **HIGHLY ATTENTIVE** | Default case (student remained alert for the vast majority of the session). |
